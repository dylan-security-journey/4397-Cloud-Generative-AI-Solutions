# Cloud Economics and Billing

## 📌 Fundamentals of Pricing
- AWS offers multiple payment models:
  - **On-demand**: Pay-as-you-go, no upfront commitment.
  - **Reserved Instances**: Commit to use for 1–3 years in exchange for discounts.
  - **Savings Plans**: Flexible pricing model with significant savings.
- **Key cost drivers in AWS**:
  1. Compute
  2. Storage
  3. Outbound data transfer
- **Data transfer pricing**:
  - Inbound transfer → usually free
  - Transfers between AWS services in the same region → usually free
  - Outbound transfer → charged (but the more data you transfer, the cheaper per GB)
- **Best practices**:
  - Start cost optimization early.
  - Services are priced independently and transparently → pay only for what you use.
  - No long-term commitments unless you choose to save via reservations.
  - Shutting down unused instances can reduce costs by **70% or more** compared to 24/7 usage.

## 📌 Delaware North Case Study
- **Company Overview**:
  - Operates in hospitality, food service, and retail at stadiums, airports, and national parks.
  - ~$3 billion enterprise with global operations.
- **Challenges**:
  - Managing 225 on-premises servers.
  - High IT costs and strained resources.
  - Constant need to upgrade and replace servers.
- **AWS Migration Benefits**:
  - Reduced infrastructure overhead.
  - Improved scalability and cost efficiency.

## 📌 Billing and Cost Management
- **AWS Billing and Cost Management Service**:
  - Pay AWS bills, monitor usage, analyze costs.
  - Charges applied to credit card on file monthly.
- **Features**:
  - Tools to gather cost and usage information.
  - Analyze **cost drivers** and **usage trends**.
  - Set **budget alerts** if costs exceed thresholds.
  - Identify **largest AWS investments**.
  - Simplify accounting for multiple AWS accounts.
- **Key Actions**:
  - Estimate and plan AWS costs.
  - Receive alerts for budget thresholds.
  - Monitor and optimize resource usage.
